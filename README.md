# E-commerce Database Design using MySQL

## Project Overview
This project focuses on managing and analyzing E-commerce order data using MySQL. It includes table creation, data insertion, and SQL queries to extract meaningful business insights.

## Tools Used
- MySQL
- SQL

## Project Activities
- Created database tables to store E-commerce order information.
- Inserted sample data into the database.
- Retrieved cancelled orders and UPI payment records.
- Analyzed cities based on product categories.
- Used GROUP BY, HAVING, DISTINCT, and Subqueries.

## Project Files
1. 01_create_tables.sql – Table creation queries.
2. 02_insert_data.sql – Data insertion queries.
3. 03_analysis_queries.sql – SQL analysis and problem-solving queries.

## Key Learning
- Database creation and management.
- SQL filtering and sorting.
- Aggregate functions and grouping.
- Subqueries and data analysis.
